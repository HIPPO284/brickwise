# Data policy

Allowed: permitted Rebrickable metadata CSV/API workflows, properly licensed LDraw geometry, project-owner photographs, and photographs with explicit recorded consent.

Prohibited: scraping or downloading images from LEGO.com, BrickLink, Rebrickable, search engines, social media, product pages, marketplaces, blogs, fan sites, or user uploads without consent. Do not automatically self-label or add model predictions to training data.

Metadata, geometry, rendered images, and user images remain separate provenance classes. Every imported/generated file requires a hash and source record. Do not commit production data or private user data.
